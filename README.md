# Behaviour-of-Sandwich-Composites
The behaviour of sandwich composites under flexural load for variation in core thickness was experimentally found. 
The face sheets were glass fiber which were saline treated 10 mm cloth and the core was PY Foam Board with a density of 115 kg/m^3. The resine used was GY-257 and the hardner used was C-2963. The composite was made using a combination of hand lay up and compression moulding methods. 
They were tested in a Universal Testing Machine for 3 point bending, applying a normal load until failure.
As the thickness of the core increased, the weight of the material increased by 56%, the flexural rigidity increased by 1.5 times. This trend peaked at a value where the core is twice as thick as the face plate, after which the flexural rigidity plateaued even with increasing core thickness.
